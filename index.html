Sistema web de gestão de academia: usuários, planos, pagamentos e fichas de treino.

Objetivo: centralizar a gestão da academia do proprietário e dar ao cliente acesso ao seu plano, aos seus pagamentos e às suas fichas de treino.

Projeto desenvolvido no Estágio Obrigatório do curso de Ciência da Computação (UniFil), para um único proprietário de academia. O sistema atende dois perfis: o Proprietário, que administra tudo, e o Cliente, que acompanha e gerencia seus próprios dados.

Sobre o Projeto

Problema

A gestão da academia era feita de forma manual: cadastro de alunos, controle de planos e pagamentos e fichas de treino sem um sistema único, o que gera retrabalho, erros e falta de histórico.

Solução

Aplicação web em que o frontend React consome uma API REST em Spring Boot. Os dados ficam em PostgreSQL, com o esquema versionado por migrations Flyway.

Tecnologias

  • Java
  • Spring Boot
  • React
  • TypeScript
  • PostgreSQL
  • Astah UML
  • Figma
  • Heflo (BPMN)

Arquitetura

O backend é organizado em camadas, uma para cada recurso: Entity → Repository → Service → Controller, com DTOs de request e response. A validação fica na entidade (model). O frontend é organizado em páginas e componentes reutilizáveis, como Sidebar, Navbar e modais de confirmação e de formulário.

O modelo de dados tem as entidades Usuário, Autenticação, Plano, ClientePlano, Pagamento, Ficha, Exercício e FichaExercício.

Casos de Uso e Cronograma

Casos de uso

Caso de uso Ator Descrição
Gerenciar Clientes Proprietário CRUD completo de clientes: cadastrar, listar, editar e excluir, com validações como CPF válido e único.
Gerenciar Planos Proprietário CRUD completo dos planos oferecidos pela academia.
Gerenciar Fichas Cliente e Proprietário CRUD completo de fichas de treino, com exercícios do catálogo (séries, repetições, carga e descanso). O Cliente gerencia só as próprias fichas; o Proprietário gerencia as de todos e atribui fichas aos clientes.
Controlar Plano Cliente Assinar um plano, cancelar a assinatura e consultar o histórico. A assinatura nasce "Aguardando Pagamento" e passa a "Ativo" quando o pagamento é confirmado.
Controlar Pagamento Cliente Realizar o pagamento da assinatura via gateway de pagamento e consultar o histórico de pagamentos. É uma extensão de Controlar Plano.

Gerenciar Planos Documentação concluída (especificação e diagramas). Sistema implementado com as mesmas validações, ajustes da pré-banca, formulário em modal e paginação. Concluído

Controlar Pagamento Especificação concluída. A implementação será feita após Controlar Plano, com integração a um gateway de pagamento. Previsto
